Pocket Mandelbrot Viewer
A simple, bare-bones, mandelbrot set viewer that can run in the browser URI bar! No web server or internet required. It might be a bit laggy because it doesn't use webworkers or anything, but it's super simple and fits under 3kb. If you want to read more about it, check out the github page (linked below)

This project was made for SHRINK, a Hack Club program
